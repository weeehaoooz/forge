Badge Directive

Badges are small status descriptors and numerical counters for UI elements. They appear in proximity to host elements (such as buttons, avatars, icons, and cards) and support configurable sizes, threshold clamping (e.g. 99+), dot notification indicators, and live pulse animations.

Maximum Threshold Clamping (e.g. 99+)

When numerical counts exceed the configured talosBadgeMax, the badge automatically displays the threshold value with a + post-script.
