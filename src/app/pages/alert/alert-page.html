Architecture Guide

When to Use: Alert vs. Snackbar vs. Dialog

Understand when each feedback component fits best in enterprise UX
TalosAlert & Service

Contextual Alert

In-page flow / persistent banner: Stays visible until user dismisses or condition is resolved. Ideal for quota warnings, validation summaries, or system outages.

TalosSnackbarService

Toast / Snackbar

Floating overlay: Ephemeral (auto-closes in 3-4s) for background operations that don't disrupt user focus (e.g., "Saved", "Synced", "Email sent").

TalosDialogService

Dialog Alert Modal

Blocking modal backdrop: Completely halts workflow and forces explicit acknowledgement before proceeding (e.g. "Session Expired", "Data Loss Warning").
